# Changelog

All notable changes to DeepAgent will be documented in this file.

## [0.9.0-alpha.1] - 2026-07-02

### CLI Alpha (Phase 1)

- Core agent runtime with skill creation from experience
- DeepAgent code mode (delegates to isolated OpenCode environment)
- Scene classification and intent routing (14 harness modules)
- Immune system, hard constraints, context compression, reasoning management
- R2-backed release distribution
- Cloudflare Pages deployment

### Known Limitations (Alpha)

- Unsigned builds only (no Apple Developer signing)
- No auto-update mechanism
- WebUI and Electron not included in this phase
