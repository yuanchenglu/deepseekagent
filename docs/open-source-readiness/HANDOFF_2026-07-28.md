# 三、当前唯一第一优先任务

将已经固化的 Runtime Task / Workspace Lease 协议接入真实 Electron Main、DeepAgent Runtime 和 DeepCode Runtime 的 task/PID 生命周期。

不要并行启动双 Runtime E2E、凭据清理、干净机或其他后继任务。

必须实现并验证：

1. Electron Main 实例化单一 `RuntimeTaskLeaseCoordinator`。
2. DeepAgent 和 DeepCode 分别通过固定 Runtime Adapter 接入，不能冒充另一 Runtime。
3. 每个真实任务必须显式声明 `read` 或 `write`。
4. 任务启动前 acquire；acquire 被拒绝时不得 spawn 进程。
5. spawn 成功后由 Main-only `bind-process` 绑定真实 PID/进程树。
6. Runtime 周期性发送 heartbeat；Main 负责 timeout。
7. Main 根据真实 process-exit、runtime-crash 和 recover 驱动状态机。
8. 正常完成、取消、超时、进程树退出、Runtime 重启和异常回收不得产生双写窗口。
9. Main 重启后从持久状态和真实存活进程重建；无法证明安全时保持 orphaned 失败关闭。
10. Renderer 与 Runtime 无法调用 Main-only 监督事件。
11. 增加真实监督器集成测试，但不得把 mock 或单元测试描述为双 Runtime E2E。
12. 从最新 `develop` 创建功能分支，提 PR，等待 Browser E2E 和完整 Electron Main/DMG workflow 真实通过。
13. 处理所有 actionable review 后合入。
14. 合入后更新 PLAN、00、10 和本交接。

这一工作单元只完成真实 task/PID 生命周期接入与监督器集成测试。
