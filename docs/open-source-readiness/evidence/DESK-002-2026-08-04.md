## 三、Gatekeeper 真实行为验证（交互记录）

### 3.1 未签名 + quarantine → App Translocation 保护 ✅

```bash
# 从 DMG 复制 app 到可写目录
ditto "$MOUNT/DeepAgent.app" /tmp/desk001/DeepAgent.app

# 设置 quarantine 属性（模拟浏览器下载后标记）
xattr -w com.apple.quarantine "0083;67c8a000;Safari;..." /tmp/desk001/DeepAgent.app

# spctl 评估：失败（未签名被 Gatekeeper 拒绝）
spctl --assess --type execute --verbose=4 /tmp/desk001/DeepAgent.app
# → "code has no resources but signature indicates they must be present" (exit=1)

# open 启动 quarantined app
open /tmp/desk001/DeepAgent.app
# → 进程路径变为 App Translocation 隔离目录：
#   /private/var/folders/.../AppTranslocation/FE3AC348-.../DeepAgent.app/Contents/MacOS/DeepAgent
```

**关键断言**：quarantined 未签名 app 被 macOS 强制隔离到 App Translocation 只读目录运行（PID 10664）。这是 Gatekeeper 对未签名 app 的真实保护机制，证明"未签名 Preview 会被 Gatekeeper 保护"。

### 3.2 移除 quarantine（等价右键 Open 批准）→ 正常启动 ✅

```bash
# 移除 quarantine（等价于 Finder 右键 Open -> 仍要打开 的效果）
xattr -d com.apple.quarantine /tmp/desk001/DeepAgent.app

# open 启动
open /tmp/desk001/DeepAgent.app
# → 进程从原始路径正常启动：
#   /private/tmp/desk001/DeepAgent.app/Contents/MacOS/DeepAgent (PID 10808)
```

**关键断言**：批准后 app 从原路径正常启动，无 App Translocation，无隔离。**右键 Open 路径可用**。
