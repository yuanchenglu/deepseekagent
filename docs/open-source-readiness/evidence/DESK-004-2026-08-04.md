## 二、发现并修复破损（PR #57 + #58）

### 2.1 updater feed URL 指向旧品牌（PR #57）
- **根因**：updater.ts 的 feed URL 指向旧 Hermes Studio（download.ekkolearnai.com / EKKOLearnAI/hermes-studio），与 DeepAgent 发布渠道（deepseekagent.starseas.org）不一致
- **修复**：主 feed → `https://deepseekagent.starseas.org/releases/desktop`，fallback → DeepAgent GitHub release
- **验证**：tsc 通过，CI 全绿

### 2.2 mac 自动更新缺 zip 目标（PR #58）
- **根因**：electron-builder.yml 只有 dmg target，workflow 不发布 zip + latest-mac.yml。electron-updater 在 mac 需要 zip 更新包，报 "ZIP file not provided"
- **修复**：
  - electron-builder.yml: mac 增加 zip target
  - workflow: 构建阶段复制 zip + latest-mac.yml 到发布产物
  - workflow: publish 上传 zip + latest-mac.yml 到 R2 并校验
- **验证**：YAML valid、concurrency contract 通过、重建生成 zip + latest-mac.yml
