## 八、遗留问题已解决：latest-mac.yml 公开 404（PR #66）

- **根因**：deepagent-landing worker（zone 路由 `deepseekagent.starseas.org/releases/*`）的 `proxyFromR2` 用 `key.replace('latest', CURRENT_VERSION)` 把 `latest-mac.yml` 重写成 `0.9.0-alpha.1-mac.yml`，Electron 升级 feed 404
- **修复**：`replace(/(?<=-)latest(?=\.)/, CURRENT_VERSION)` 只匹配 CLI latest 指针，latest-mac.yml 原样返回
- **部署**：wrangler deploy（Version 55582cfb-2b81-490a-8c3c-66636cf5e1b5），R2 binding DEEPAGENT_RELEASES 保留
- **验证**：latest-mac.yml 公开 URL 200（内容 version 0.9.0-preview.1），deepagent-latest.tar.gz 仍 200（CLI 不受影响）
- **存档**：修复版 worker 源码 `scripts/landing/deepagent-landing-worker.js`
