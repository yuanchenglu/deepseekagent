# Embedded R&D Team (Code Mode)

This directory contains the **built-in, isolated OpenCode-based development team** for Deep Agent acting as CEO.

**Important**:
- This is NOT the user's local OpenCode.
- All configuration, models, skills, and state here are completely isolated.
- Users should never need to interact with this directly.

See `docs/specs/03-Code-Mode-Implementation.md` for architecture.
