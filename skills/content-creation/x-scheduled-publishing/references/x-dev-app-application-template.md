# X Developer App — Application Description Template

Use this template when the X Developer Platform asks for a 100+ word application description during app creation. Replace `@handle` with the user's actual X handle.

---

## Template (English, ≥100 words)

```
I am building a personal content automation tool that helps me share my technical articles and insights about AI/LLM agents on my X account (@handle). The app will use the X API v2 to post original content on a scheduled basis — typically 2-3 posts per week covering topics like large language models, agent architectures, open-source AI tools, and product thinking. All content is original and created by me. The app uses OAuth 2.0 PKCE for secure authentication and will only post to my own account. No automated replies, no bulk following, no spam behavior. This is purely a personal productivity tool to maintain a consistent content publishing cadence on X.
```

## Notes

- Keep it honest — X reviews these and inconsistent usage patterns can trigger suspension
- If the user's actual topic varies (not AI), adjust the content description accordingly
- The key assurances X wants: OAuth PKCE (secure), single-account only (no spam), original content (not a repost bot), no automated engagement (replies/likes/follows)
