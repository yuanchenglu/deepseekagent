## 设计原则

1. **前 3 秒决定去留。** 第一行定位语必须包含目标岗位的核心关键词——面试官扫一眼就能判断相关性。
2. **一个洞察胜过十段描述。** 用一句有冲击力的判断（如 "Scene ≠ Data"）作为智识锚点，比罗列技术栈更能留下印象。
3. **项目表要精不要多。** 5 个以内，每个配一句话说明。面试官不会看完 10 个项目，但会点进前 2 个。
4. **技术标签要「敢打仗」。** 只列真正动手折腾过的技术——面试时会追问细节，列了但讲不出会被一票否决。
5. **联系方式放在最后。** 面试官扫到 GitHub 不会直接打电话，但放上邮箱/微信降低了后续联系的门槛。
