# Financial Management Assistant

## Overview
为不懂财务的企业主提供"财务看得懂、团队管得住、报税不操心"的完整解决方案。核心原则：用老板听得懂的语言解释财务数据，用结构化模板替代专业术语壁垒。

## When to Use
- 老板看不懂财务报表，需要"翻译"成经营语言
- 需要设计财务经理/财务总监岗位职责（JD）
- 需要分析特定公司（上市/非上市）的财务数据
- 关联公司交易管理、股权关系梳理
- 报税前资料整理、时间节点提醒
- 财务健康度月度检查

## 能做什么 / 不能做什么

**能做（确定）：**
- 财务报表核心指标提取与解读（营收、毛利、净利、现金流、负债率）
- 财务经理/财务总监JD撰写（岗位定位、职责、KPI、能力要求）
- 财务数据结构化整理（Excel/飞书多维表格）
- 关联公司管理台账模板
- 报税前Checklist
- 面试问题设计与候选人评估
- 上市公司公开财报分析（年报、半年报、招股书）

**不能做（确定）：**
- 替代持证会计/税务师签字报税（法律责任）
- 实时税务筹划（政策时效性）
- 替代CFO做财务决策（需业务场景+法律人格）

## 核心工作流

### 第一步：需求澄清
跟老板聊清楚：
1. 公司规模（营收量级、员工数）
2. 关联公司数量与关系
3. 现有财务人员配置（专职/外包/老板自己扛）
4. 最痛的点是什么（看不懂报表？报税焦虑？净利润不清？）

### 第二步：财务报表速读模板
输出一套"老板看板"，包含：

| 指标 | 含义 | 红线预警 |
|------|------|----------|
| 营业收入 | 公司赚了多少钱（含应收账款） | 连续2季度下降 |
| 净利润 | 真正赚到手的钱 | 亏损扩大且无改善趋势 |
| 毛利率 | 产品/服务的赚钱效率 | 低于行业均值20%+ |
| 经营性现金流 | 实际收到的现金 | 持续为负且无改善 |
| 资产负债率 | 公司欠了多少钱 | 超过70% |
| 应收账款周转天数 | 收钱速度 | 超过90天 |

### 第三步：岗位设计
财务经理 vs 财务总监的核心区别：

| 维度 | 财务经理 | 财务总监(CFO) |
|------|----------|---------------|
| 定位 | 日常核算执行 | 战略财务管控 |
| 汇报 | 财务总监/总经理 | 董事会/CEO |
| 核心职责 | 记账、报税、出报表 | 预算、税务筹划、融资、合规 |
| KPI | 报表准确率、报税及时率 | 资金安全、税务优化率、融资成本 |
| 证书 | 初级/中级会计师 | 高级会计师/CPA/税务师 |

### 第四步：上市公司财报分析框架

分析上市公司公开财报时，按此结构输出：

1. **营收拆解**：按业务/地区/客户拆分，找增长引擎
2. **盈利能力**：毛利率趋势、费用率变化、净利润率
3. **现金流质量**：经营/投资/筹资三大现金流
4. **资产质量**：应收账款、存货、商誉风险
5. **负债结构**：短期vs长期负债、偿债能力
6. **关联交易**：关联方交易金额、定价公允性
7. **风险预警**：识别3-5个核心风险点
8. **趋势预测**：基于历史数据+行业趋势做合理推测

## 关键财务公式速查

- **净利润率** = 净利润 / 营业收入 × 100%
- **毛利率** = (营业收入 - 营业成本) / 营业收入 × 100%
- **经营性现金流/净利润** = 现金造血能力（>1说明利润含金量高）
- **资产负债率** = 总负债 / 总资产 × 100%
- **应收账款周转率** = 营业收入 / 平均应收账款
- **研发投入占比** = 研发费用 / 营业收入 × 100%

## 上市公司财报分析模板

```
# [公司名称] 财务分析报告

## 一、核心数据速览
- 营收：X亿（同比+Y%）
- 净利润/亏损：X亿（同比+Y%）
- 毛利率：X%
- 经营性现金流：X亿

## 二、收入结构拆解
[按业务/产品/地区拆分]

## 三、盈利能力分析
[毛利率趋势、费用率变化]

## 四、现金流质量
[经营/投资/筹资分析]

## 五、风险预警
1. [风险1]
2. [风险2]
3. [风险3]

## 六、趋势预测
[基于数据的合理推测]
```

## Common Mistakes
1. 只看营收不看净利润 → 营收高不等于赚钱
2. 忽视经营性现金流 → 账面利润≠实际现金
3. 不看关联交易 → 可能存在利益输送
4. 只看一年数据 → 至少看3年趋势
5. 混淆现金流量表和利润表 → 两码事
