# 游戏化系统设计速查

## 六层模型

### 1. 核心循环

```
动作 → 即时反馈(硬件) → 看变化(App) → 分享 → 继续
```

硬件反馈 > App 反馈。因为用户做动作时不看手机。

### 2. 等级体系

- 前期快：前 5 级 < 1 周可达 → 制造"我很强"错觉
- 后期慢：指数增长 → 稀缺感和追求目标
- 解锁驱动：每个等级解锁新功能/特权，不只是数字变大

### 3. 成就系统

```
70% 可预期 → 给用户明确目标
20% 挑战性 → 给硬核用户追求
10% 隐藏惊喜 → 制造传播话题
```

分类：击杀/行为/社交/时间/恶搞（5类）

隐藏成就：不公开条件，触发时惊喜弹出 → 用户自发分享

### 4. 战队系统（留存核心）

```
个人排行 → 前 10% 有参与感
战队排行 → 100% 有归属感

"我虽然菜，但我战队强"
```

要素：人数(5-15)、门槛(Lv.X)、赛季(周/月)、队内排行(MVP/新人/警告)

### 5. 领地争夺（UGC 发动机）

```
城市网格(300m×300m) → 战队积分占领 → 可视化 → 推送"你的领地被攻击了"

产生的故事线：
- "我们小区被隔壁战队偷了！今晚夺回来！"
- "华科 vs 武大灭蚊德比"
```

### 6. 经济系统

| 货币 | 获取 | 用途 |
|------|------|------|
| 免费币 | 击杀、成就 | 皮肤、道具 |
| 战队币 | 排行奖励 | 战队升级 |
| 付费币 | 充值/赛季奖励 | 高级皮肤 |

消耗品增加深度：双倍卡、护盾、召集令。

---

## 防作弊

- 不作恶：不牺牲正常体验
- 不公告：反作弊规则不公开
- 梯度处罚：轻微→不计排行，严重→赛季禁赛

作弊检测维度：电流波形差异、IMU 挥拍检测、击杀频率上限、硬件签名防篡改。

---

## 内容素材（系统自动生成）

1. 击杀回放卡片（可分享）
2. 周报/月报（用户数据回顾）
3. 赛季战报（战队排名、高光）
4. 热力图截图（"看看你们区的蚊情"）
5. 成就解锁海报
