# 电蚊拍击杀检测案例

> 完整演示 hardware-product-feasibility-analysis 七步法

## 用户需求

"电蚊拍通过蓝牙连接手机，每拍死一只蚊子就记录击杀个数+1。核心是如何识别击杀事件。"

## 第一步：物理原理拆解

电蚊拍电路：
```
电池(DC 3-4.2V) → 阻塞振荡器 → 升压变压器 → Cockcroft-Walton倍压整流 → 高压金属网(2000-4000V)
```

击杀时：蚊虫桥接内外层 → 高压击穿 → 电弧放电 → 储能电容快速放电 → 电压骤降 → 振荡器重新充电

**关键信号参数**（基于典型电路推算）：
- 电池端电流尖峰：50-500mA，持续 0.1-5ms
- 高压端电压跌落：从 2000-4000V 骤降，幅度 50%+
- 声学特征：2-8kHz "噼啪"声，持续 50-200ms

## 第二步：方案对比

参考实现 [MosquitoKiller](https://github.com/Saur0o0n/MosquitoKiller) (2021) 使用高压侧电压跌落检测。

| 维度 | LV 电流检测（主方案） | HV 电压检测（MosquitoKiller） | 声学辅助 |
|------|---------------------|---------------------------|---------|
| 实现难度 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐ |
| 安全性 | ✅ 低压侧 | ⚠️ 需分压器隔离 | ✅ 非接触 |
| 量产一致性 | ⚠️ 待验证 | ❌ 每台需调分压电阻 | ✅ 好 |
| 信号区分度 | ⚠️ 待验证 | ✅ 已实战验证 | ✅ 独有声纹 |
| 成本 | ¥2-3 | ¥5-8 | ¥1-2 |

**推荐**：电流 + 声学双模（安全 + 低成本 + 低误判）

## 第三步：假触发分析

| 假触发场景 | 电流特征 | 声音特征 | 判别策略 |
|-----------|---------|---------|---------|
| 金属物体短路 | 更短、更高幅度 | 金属撞击声(8-15kHz) | 脉宽+频谱双过滤 |
| 灰尘/湿气漏电 | 持续低幅度 | 无声或微弱 | 无尖峰→忽略 |
| 手指触碰 | 极高电流+长时间 | 人声 | 电流上限阈值 |
| 同一蚊子多次电弧 | 50ms内多尖峰 | 连续声 | 700ms去重窗口 |
| 空挥 | 无变化 | 无击杀声 | 双通道均无信号 |

## 第五步：关键风险

1. **电流区分度不足（最高风险）**：Phase 1 用示波器验证
2. **EMI 干扰**：MosquitoKiller 作者需用锡纸包裹所有电路板才解决 — PCB 阶段必须前置考虑
3. **量产一致性**：不同品牌电蚊拍升压电路参数差异大，需自适应阈值或出厂校准
4. **高压安全**：MCU 电路与 4000V 电网爬电距离 ≥ 6mm

## 第六步：MosquitoKiller 源码分析

**检测算法**（MosquitoKiller.ino L389-423）：

```cpp
// 追踪充电峰值电压
if (results > max_val) max_val = results;

// 放电判定：当前值 < 峰值的 50% 且 峰值 > 阈值
if (results < (max_val * 0.5) && max_val > 100) {
    // 700ms 去重窗口
    if ((last_kill + kill_grace_period) < millis()) {
        kill_mosquito();  // 计数 +1
    }
    max_val = results;
}
```

**可直接继承的经验参数**：
- 去重窗口：700ms（作者实测调出，不是 200ms）
- 连杀窗口：1.5秒
- 跌落阈值：峰值的 50%
- 按键消抖：10 次采样投票 + 600ms 松手容忍

**作者踩的坑**：
- EMI 干扰导致"组装后完全无法计数"（README L71）
- 分压电阻需逐台调整（量产不友好）

**他们的缺失（我们的差异化空间）**：
- 无蓝牙/App/云端/社交

## 第七步：Phase 1 验证计划

测试矩阵（≥ 50 次真击杀 + 50 次金属短路 + 20 次潮湿漏电）：
```
示波器双通道同步采集：电池端电流 + 高压端电压
决策：LV 电流 vs HV 电压，哪种更适合量产
EMI 评估：PCB 靠近高压变压器时的信噪比
```

Go/No-Go 标准：真击杀 vs 金属短路可区分度 ≥ 90%
