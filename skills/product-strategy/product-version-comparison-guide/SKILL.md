# Product Version Comparison Guide Creator

## Purpose
Create comparison guides that help buyers choose the right product version, focusing on benefits and use cases rather than technical specs.

## Core Principles
1. **Buyer-centric**: Answer "Why should I buy this version?" not "What features does it have?"
2. **Visual hierarchy**: Use tables, diagrams, and decision trees
3. **Clear differentiation**: Each version must have distinct value proposition
4. **Actionable**: Help users make a decision quickly

## Document Structure

### 1. Quick Decision Section (30-Second Read)
```
🎯 30秒快速决策
┌─────────────────────────────────────────────────────┐
│ • 个人尝鲜 → 经理版 ¥299                            │
│ • 小团队协作 → 总监版 ¥888                          │
│ • 企业深度应用 → CEO版 ¥1888                        │
│ • 全面掌控 → 董事长版 ¥3500                         │
└─────────────────────────────────────────────────────┘
```

### 2. Visual Comparison Table
| 版本 | 价格 | 核心定位 | 适合谁 | 关键差异 |
|------|------|----------|--------|----------|
| 基础版 | ¥X | 定位描述 | 目标用户 | 主要卖点 |

### 3. Detailed Version Breakdown
For each version include:
- **一句话定义**: What it is in simple terms
- **适合人群**: Specific user personas
- **你能得到**: Concrete benefits
- **局限性**: Honest limitations
- **使用场景**: Real-world examples

### 4. Decision Tree
```
决策流程图（文字版）:

开始
  ↓
是个人尝鲜? → 是 → 经理版
  ↓ 否
需要团队协作? → 是 → 总监版
  ↓ 否
需要安装到本地? → 是 → CEO版
  ↓ 否
需要全部功能? → 是 → 董事长版
```

### 5. FAQ Section
Address common questions:
- Can I upgrade later?
- What's the difference between X and Y?
- Is the basic version enough for me?

## Formatting Guidelines

### Visual Elements
- Use emoji bullets (🎯, 💡, ⚠️, ✅)
- Create ASCII diagrams for hierarchy
- Tables for side-by-side comparison
- Clear section headers with icons

### Language Style
- Conversational, not technical
- Focus on outcomes, not features
- Use "你" (you) to address reader directly
- Avoid jargon unless explained

### Mobile Optimization
- Short paragraphs (2-4 lines max)
- Plenty of white space
- Clear visual breaks between sections
- Scannable with bold key points
