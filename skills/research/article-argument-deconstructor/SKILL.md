# 文章论证逻辑解构分析器

## 目的
对观点性、预测性、分析性文章进行系统性逻辑审查，识别强论证与弱论证，帮助用户建立"批判性阅读"能力。

## 工作流程（五步走）

### 第一步：梳理论证骨架
将文章拆解为"章节-核心论点-论证方式-关键证据"四维度表格：

```markdown
| 章节 | 核心论点 | 论证方式 | 关键证据/依据 |
|------|---------|---------|--------------|
| 引言 | ... | ... | ... |
```

**论证方式分类标签：**
- 直接断言（无证据）
- 资历背书（证人资格）
- 类比论证（A像B，B如此，故A如此）
- 归纳论证（从个案推一般）
- 演绎论证（如果P则Q，非Q故非P）
- 数据论证（统计/数据支撑）
- 概念提炼（定义/框架重构）

### 第二步：逐层检验论证链条
对每一个论证环节，用以下模板检验：

```
**论证环节X**
- 逻辑形式：[XX推理/类比/归纳...]
- 大前提：[xxx]
- 小前提：[xxx]
- 结论：[xxx]

**检验结果：**
- ✅ 前提可靠
- ⚠️ 前提存疑 → [具体说明]
- ❌ 前提不成立 → [具体说明]
- ⚠️ 逻辑跳跃 → [从A到B缺少过渡论证]
```

### 第三步：识别逻辑谬误
对照常见谬误清单进行扫描：

| 谬误类型 | 检测方法 | 文章中可能的表现 |
|---------|---------|----------------|
| 诉诸权威 | 作者用身份/经验代替证据 | "我有XX年经验"→"所以我说的对" |
| 类比不当 | 比较两个事物的关键差异 | 忽略了重要的维度差异 |
| 虚假因果 | 相关不等于因果 | A发生后B发生了 → A导致B |
| 循环论证 | 用结论证明前提 | 先定义X是"没优势的"，然后说X会消失 |
| 虚假二分 | 是否排除了其他可能性 | "只有A或B两种活法" |
| 幸存者偏差 | 样本是否有偏 | 用失败案例证明整体崩塌，忽略成功者 |
| 以偏概全 | 个案推广的范围是否合理 | 从少数观察推出全行业结论 |
| 绝对化表述 | 是否留有概率空间 | "只剩"、"一定"、"最危险" |
| 难以证伪 | 结论是否可被证伪 | "什么是机器给不了的"—未定义 |

### 第四步：评估核心类比/假设
如果文章使用了**类比**（如房地产 vs 教培），必须做差异分析：

```markdown
| 维度 | 事物A | 事物B | 差异是否影响结论？ |
|------|------|------|------------------|
| 产品属性 | ... | ... | ... |
| 政策逻辑 | ... | ... | ... |
| 准入门槛 | ... | ... | ... |
```

**判断标准：**
- 如果差异**不影响**类比要点 → 类比有效
- 如果差异**直接影响**结论 → 类比无效或需要补充论证

### 第五步：综合评分与总结
用五维度给文章打分（星级评分）：

| 维度 | 评分 | 说明 |
|------|------|------|
| 论证结构 | ★★★★☆ | 层层递进还是跳跃混乱 |
| 证据充分性 | ★★☆☆☆ | 数据/研究/案例是否充分 |
| 逻辑严密性 | ★★★☆☆ | 有无跳跃、谬误 |
| 洞察深度 | ★★★★★ | 框架是否有新意和穿透力 |
| 结论可信度 | ★★★☆☆ | 方向对不对，预测准不准 |

**最终输出格式：**
```
**一句话点评**：[xxx]

**总体判断**：
> 文章的[xx]比[xx]更值得信任。读这篇文章，应该吸收它的[xx]，而不是迷信它的[xx]。
```

## 输出风格要求
1. 严格分析，不连贪贴金
2. 指出缺陷的同时，也要承认优点
3. 用**具体文章内容**作为证据，不做空泛批评
4. 标注论证强度时使用 ✅/⚠️/❌ 三级标记
5. 最终给出**可操作的阅读建议**：该吸收什么、该警惕什么

## 常见陷阱
- **不要只批不建**：分析的目的不是"打倒"文章，而是"理解"文章
- **不要超越文本证伪**：批评文章的论证缺陷，不是用自己的知识去"纠正"文章的观点
- **不要歧义误用**：区分"类比不当"和"类比有限"——类比从来不是完美的，关键是看差异是否破坏结论
- **不要忽略语境**：文章的"预测"和"研究报告"的证据标准不同，不能用同样标准审查

## 与其他技能的区别
- 不是**文章摘要**：不重复内容，而是审查论证
- 不是**文章合成**：不改写文章，只分析逻辑
- 不是**产品分析**（khazix-hv-analysis）：不分析外部市场，只分析文章内部论证结构
