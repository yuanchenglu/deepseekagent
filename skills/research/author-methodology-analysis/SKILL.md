# 作者方法论分析器

## 使用场景

- 分析某个博主/作者的写作方法论
- 从多篇文章中提炼选题规律、标题模式、结构框架
- 生成可复用的写作组件（选题脚手架、标题公式、开头模板等）
- 输出HTML报告供参考

## 核心分析维度

### 1. 选题系统
- 选题来源（热点/痛点/行业/个人经验）
- 选题频率和节奏
- 选题与受众的匹配度

### 2. 标题模式
- 标题公式（数字+具象、反常识、悬念等）
- 标题长度分布
- 高CTR标题的共性特征

### 3. 文章结构
- 开头模式（钩子类型：故事/数据/反常识/痛点）
- 段落节奏（长短交替、信息密度）
- 结尾模式（总结/行动号召/悬念）

### 4. 表达风格
- 人称使用（第一人称/第二人称/第三人称）
- 句式特点（短句/长句/问句）
- 口语化程度
- 金句句式

### 5. 案例库
- 案例类型（个人经历/行业数据/对比案例）
- 案例使用频率
- 案例与论点的关联方式

## 分析流程

### Step 1: 收集文章
```bash
# 如果是本地文件
ls ~/Documents/articles/*.md

# 如果是飞书文档
lark-cli docs +fetch --doc "DOC_TOKEN" --format json

# 如果是微信文章（使用 wechat-to-md MCP）
# convert_article(url, output_dir)
```

### Step 2: 提取元数据
每篇文章提取：
- 标题
- 发布时间
- 字数
- 关键词/主题标签

### Step 3: 逐篇分析
对每篇文章分析：
- 选题角度
- 标题公式
- 开头钩子
- 段落结构
- 金句/名言
- 结尾方式

### Step 4: 聚合统计
汇总多篇文章的规律：
- 最常用的标题公式 TOP3
- 最常见的开头模式 TOP3
- 高频出现的金句句式
- 选题方向分布

### Step 5: 生成框架
从分析结果中提取可复用组件：
- 选题脚手架（3-5个选题模板）
- 标题公式集（5-10个标题模板）
- 开头模板（3-5种开头方式）
- 段落句式库
- 转场句模板
- 金句生成器
- 发布前检查清单

## 使用示例

### 分析单个博主
```bash
# 1. 先用 wechat-to-md 归档文章
# 2. 然后分析
python3 analyze.py ~/output/博主名/
```

### 批量分析
```bash
# 分析多个博主
for blogger in ~/output/*/; do
  python3 analyze.py "$blogger" --output "${blogger}methodology.md"
done
```

## 注意事项

- 分析需要至少5-10篇文章才能得出可靠规律
- 标题分析需要原始标题，不要使用优化后的标题
- 金句提取需要保留原文上下文，避免断章取义
- 生成的框架是参考，不是模板——需要根据自己的风格调整

## 与其他工具的配合

- **wechat-to-md**: 先归档文章，再分析方法论
- **wechat-article-archiver**: 自动采集+归档+初步分析
- **飞书文档**: 分析结果可以同步到飞书知识库
